# Bodywise Remedy — App Store Growth and Review Strategy

Updated: 9 August 2026

This plan is for improving Bodywise Remedy’s App Store discoverability, conversion, and early review quality after the first approved release.

## Main ASO goal

Make the product page immediately answer three user questions:

1. Is this a calisthenics/bodyweight workout app?
2. Is it safe and simple enough for my body today?
3. Why should I subscribe instead of using random videos?

## Positioning

Primary positioning:

Bodywise Remedy is a guided bodyweight strength coach that adapts the workout to the user’s goal, mood, pain check, level, and available time.

Avoid positioning it as:

- A medical rehab app
- A generic YouTube-style workout library
- A bodybuilding app
- A hard-core athlete-only calisthenics app

Best market wedge:

Beginner-friendly bodyweight strength with body-aware guidance.

## Search strategy

Primary search themes:

- calisthenics
- bodyweight workout
- home workout
- no equipment workout
- beginner strength
- core workout
- knee-friendly workout
- mobility
- push-up / plank / squat

Do not use competitor app names in keywords or description.

## Product page conversion strategy

The first visible message should not be “subscribe.” It should be:

Start with a plan that fits how your body feels today.

Then the subscription should feel like the next step:

Unlock your 4-week strength path.

Recommended conversion sequence:

1. User lands on product page.
2. Screenshots show the app is clearly calisthenics/bodyweight.
3. First sentence promises a workout matched to the body today.
4. Free daily workout reduces hesitation.
5. Premium is framed as structured progression, not a paywall.
6. User sees trial after understanding the outcome.

## First-launch review strategy

Do not ask for a rating on first launch, during onboarding, or before the user finishes a workout.

Ask only after a positive signal, such as:

- User completes at least 2 workouts.
- User marks a workout as “good,” “strong,” or similar.
- User comes back on a later day.
- User views progress or completes a weekly milestone.

Suggested timing:

1. First workout completed: no App Store review prompt. Show encouragement only.
2. Second positive workout: show a soft in-app question first: “Is Bodywise helping you train more clearly?”
3. If user taps a positive face, trigger Apple’s review request after a short delay.
4. If user taps neutral/negative, do not ask for an App Store review. Ask what felt off and use that to improve the next workout.

Suggested soft prompt copy:

“Is Bodywise helping you train more clearly?”

Positive button:

“Yes, it helps”

Neutral/negative button:

“Not yet”

If positive:

“That’s great to hear. A quick rating helps more people find Bodywise.”

If not yet:

“Thanks — we’ll use this to make your next plan feel better.”

Important Apple-safe behavior:

- Do not reward users for reviews.
- Do not pressure users to leave five stars.
- Do not ask immediately on first launch.
- Do not repeatedly nag.
- Use Apple’s official review request flow where possible.

## First 30 days launch plan

Week 1:

- Confirm product page is live in all intended countries.
- Share the direct App Store link with 20 trusted testers.
- Ask testers to use the app, not just download it.
- Collect private feedback before asking for public reviews.

Week 2:

- Update promotional text if users repeat the same benefit in feedback.
- Replace weak screenshots with the clearest app-like screens.
- Publish short social clips showing the start flow, body check, and movement preview.

Week 3:

- Add one App Store review prompt moment after positive workout completion.
- Prepare version 1.1 release notes around “clearer dashboard, guided progression, and smarter body check.”
- Monitor which screenshot and product-page wording users understand fastest.

Week 4:

- Improve the first three screenshots based on conversion.
- Add localized metadata for high-opportunity English-speaking countries first if needed.
- Prepare a short landing page that links directly to the App Store.

## Screenshot creative direction

The app should look premium, not instructional-manual-like.

Visual rules:

- Show actual app screens.
- Keep text overlays short.
- Use strong contrast.
- Lead with the Start Workout screen.
- Show the body check because it makes Bodywise feel adaptive.
- Show movement preview because users need trust.
- Show the 4-week path because that is the paid outcome.

Avoid:

- Generic stock fitness photos
- Screens that look like a website landing page
- Too many text blocks
- Repeated exercise media
- Labels like “real human loop”

## Metadata maintenance

Update promotional text whenever there is a meaningful feature or seasonal push. Promotional text can be refreshed more easily than the app description.

Only update app name, subtitle, description, screenshots, and keywords when preparing a new version or when App Store Connect allows metadata editing for the current app status.
